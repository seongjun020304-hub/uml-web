# 약속: 배치 주석

- 상태: 초안
- 정하는 영역: sync
- 쓰는 영역: class, sequence, app
- 예시: `docs/contracts/examples/01-class-basic`의 `%% @layout Animal 120 80`

사람이 캔버스에서 옮긴 상자의 위치를 Mermaid 코드 안 `%%` 주석에 적는 형식이다. 파서는 이 주석을 해석하지 않고 `comments`로 넘긴다(`model-json.md` 6절). 형식과 뜻은 이 문서가 정한다. 이 문서와 예시가 다르면 이 문서가 기준이다.

## 1. 형식

```
%% @layout <이름> <x> <y>
```

| 칸 | 뜻 |
| --- | --- |
| `<이름>` | 요소의 이름. 클래스는 `classes[].name`, 시퀀스는 `participants[].name`. **`label`이 아니다.** 공백을 포함할 수 없다. |
| `<x>`, `<y>` | 정수. 음수도 된다. 소수와 단위(`px`)는 쓰지 않는다. |

- 한 줄에 요소 하나를 적는다. 줄 앞 들여쓰기는 자유다.
- `%%`와 `@layout` 사이 공백은 0개 이상, 나머지 칸 사이 공백은 1개 이상이다.
- 이 형식에 정확히 맞지 않는 줄(칸 수가 다르거나 숫자가 아닌 줄)은 배치 주석이 아니라 일반 주석이다. 오류를 내지 않는다.
- `model-json.md`의 `comments[].text`(앞뒤 공백을 뺀 줄 원문)에도 같은 형식을 적용할 수 있다. class·sequence는 `comments`에서 읽어도 되고, sync의 읽기 함수를 써도 된다.

## 2. 좌표 기준

이 문서의 좌표는 **캔버스 좌표**다. `model-json.md` 2절의 원문 위치(줄·칸)와는 다른 좌표계다.

| 항목 | 기준 |
| --- | --- |
| 기준점 | 상자의 **왼쪽 위** 꼭짓점 |
| 원점 | 캔버스 원점 (0, 0). 다른 상자 기준 상대 좌표가 아니다. |
| 단위 | **확대 100%(grid 10) 기준 px**. 화면 확대 배율과 무관하다. UMLet `.uxf`의 `<coordinates>` 저장 기준과 같다. |
| 크기 | 적지 않는다. 너비·높이는 내용으로 늘 다시 계산한다(class 설계 9절). |

예시 01의 `%% @layout Animal 120 80`은 `Animal` 상자의 왼쪽 위가 (120, 80)이라는 뜻이다.

시퀀스 참여자는 **머리 상자**(`participant:<name>`)의 왼쪽 위를 적는다(`docs/sequence/design.md` 3절). 몸통 위치는 머리 상자에서 정해지므로 적지 않는다.

## 3. 적는 대상

- **사람이 손으로 옮긴 상자만** 적는다. class 설계 9절의 "고정 위치"가 이것이다.
- 옮기지 않은 상자는 적지 않는다. 처음 배치가 결정적이므로 같은 코드는 같은 그림이 된다.
- 연결선 꺾임점과 시퀀스 메시지 위치는 적지 않는다. 늘 다시 계산한다(class 설계 9절, sequence 설계 9절).

## 4. 읽기·쓰기 규칙

| 경우 | 처리 |
| --- | --- |
| 같은 이름의 줄이 여럿 | 첫 줄만 유효하다. |
| 이름의 줄이 이미 있음 | 그 줄의 숫자만 바꾼다. 들여쓰기는 그대로 둔다. |
| 이름의 줄이 없음 | 마지막 `@layout` 줄 바로 아래에 더한다. `@layout` 줄이 없으면 `classDiagram`·`sequenceDiagram` 줄 바로 아래에 더한다. |
| 코드에 없는 이름의 줄 | 무시한다. **자동으로 지우지 않는다.** |

- 위 표에 적은 줄 말고는 바꾸지 않는다.
- 줄바꿈은 `\n`만 쓴다(`model-json.md` 1절과 같다).
- 짝 없는 줄을 지우지 않는 이유: 입력 중 이름이 잠시 바뀌어 클래스가 사라져도, 이름이 돌아오면 위치가 돌아온다.

## 5. 알려진 한계

- 이름을 바꾸면 위치가 이어지지 않는다. 옛 이름의 줄은 남는다(`id-rule.md` 1절).
- 예시 `06-seq-basic`의 `%% @layout gap 40`은 칸이 두 개라 이 형식에 맞지 않는다. 이 문서 기준으로는 일반 주석이다. 참여자 간격 같은 설정이 필요하면 새 키워드로 정한다(6절).
- 시퀀스 몸통이나 메시지를 끌었을 때 무엇을 적을지는 정하지 않았다. 지금은 머리 상자를 옮긴 경우만 적는다.
- lollipop 관계로 자동 생긴 이름(`interface0` 등)은 해석마다 같다는 보장이 없어 위치를 적어도 이어지지 않을 수 있다(`model-json.md` 9절).

## 6. 변경 절차

- 이 문서의 변경은 별도 PR로 하고, 쓰는 영역 담당 전원이 승인한다.
- 크기, 연결선 꺾임점 같은 정보를 더할 때는 새 키워드(예: `@size`, `@route`)를 만든다. `@layout` 줄에 칸을 덧붙이지 않는다. 칸 수가 다른 줄은 일반 주석으로 보므로 기존 위치가 사라지기 때문이다.
